## 两端分工

| 页 | 手机 | Windows |
|---|---|---|
| 状态 | 只读：四项就绪度、哪台机器 | 配置、配对、撤销 |
| 任务 | 主入口：审批、叫停、提交、看轨迹、点预览 | 只读 + 应急停止 |
| 设置 | 无（继承电脑端配置） | 全部 |

## 判定标准

1. 手机锁屏收到通知 → 解锁 → 看到命令 → 批准 → 任务继续。全程不碰电脑。
2. 断网后恢复，事件流从断点续上，不重复不丢。
3. 手机丢失，电脑端撤销配对后立即断连。
4. 任务只能在白名单目录内工作，越界写入被拒绝并上报。
5. 一轮结束后接着说，模型记得上一轮；会话确实续不上要明确提示，不许悄悄开新会话。
6. 手机点开预览端口，看到的就是电脑上刚跑起来的那一页；刷新即最新，不占用屏幕串流。
