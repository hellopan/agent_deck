# Android 与 Windows 界面流程

## Android APK

首版使用「设备」和「审批」两个主入口。设备内依次进入项目、工具和会话。任务详情的顶部持续显示当前电脑、项目和工具，返回时恢复原列表位置。

| 界面 | 用户操作与反馈 |
| --- | --- |
| 设备 | 添加电脑、查看连接状态与最后在线时间。每台电脑显示活动任务和待审批数量。设备在线但工具未就绪时，显示对应原因 |
| 添加电脑 | 扫描 Windows 设置窗口的二维码，核对电脑名及确认信息，等待电脑端确认。二维码过期时引导在电脑重新生成，手机权限拒绝时提示如何重新启用扫码 |
| 项目与会话 | 列出所选电脑已授权的项目和可用工具。进入会话列表后可新建或继续。没有项目时引导在电脑端设置窗口添加目录 |
| 任务详情 | 输入任务、查看增量输出与执行状态、取消运行。用户滚动查看历史时保留当前位置，并显示「跳到最新」。断线时显示等待重连，提交结果待确认时展示查询状态 |
| 审批列表与详情 | 汇总各设备待审批项。详情固定显示电脑、项目、工具及命令或变更，用户核对后可「批准一次」或「拒绝」。提交后等待 Agent 回执，过期、项目停用及已处理状态分别显示 |

双机常用路径为在设备 A 下发任务，返回设备列表打开 B，再从审批入口处理 A 的请求。进入审批详情后，审批目标来自请求本身，用户切换当前设备也不会改变该目标。

## Windows 客户端

| 界面 | 用户操作与反馈 |
| --- | --- |
| 系统托盘 | 图标和提示文字表示服务未运行、Relay 已连接或正在重连。菜单提供打开设置、打开日志和退出托盘。退出时说明后台服务继续运行 |
| 连接设置 | 显示设备名称、Relay 地址、服务状态和各工具就绪状态。提交配置后显示保存与连接结果，失败时保留输入并指出下一步 |
| 配对管理 | 生成一次性二维码，显示有效期。收到申请后显示手机身份和确认信息，允许本地确认或拒绝。撤销时展示受影响的手机 |
| 项目管理 | 本地目录选择器新增项目，列表显示名称、目录和启用状态。停用或移除前说明手机会失去访问且正在运行的远程任务会被取消。完成后显示授权状态和取消结果 |
| 日志 | 按时间、级别、项目或任务筛选。查看任务输出、连接错误和授权审计时保留当前筛选条件 |

首次安装后的路径为打开设置、确认服务连通、用目录选择器添加第一个项目、配对手机，然后在手机设备列表打开该项目。项目授权和配对确认都从电脑本地完成。

## 状态、反馈与可访问性

- 区分「设备离线」「工具未就绪」「项目停用」和「运行已中断」。状态文案同时给出适用的下一步，例如等待重连、在电脑检查工具登录、请本地管理员重新启用项目或从历史继续。
- 操作提交中显示进度，收到服务端确认后显示结果。任务提交结果未知时复用原请求查询。项目仍获授权时，过期审批可查看只读详情。项目停用或授权连接断开后，清除审批正文和任务输出。
- Android 主操作触控区域至少 48dp。大字号下允许审批详情滚动，关键操作位于系统安全区域内。TalkBack 可读出设备名、项目名、操作和状态，日志追加时保持焦点。
- Windows 设置窗口支持键盘导航，焦点顺序与界面一致。确认对话框可取消，关闭后焦点回到触发位置。两端状态都用文字表达，并检查亮暗主题中的可读性。
