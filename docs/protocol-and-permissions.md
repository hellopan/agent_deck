# 跨端协议与权限设计

## 边界与数据归属

| 组件 | 持有的数据与职责 |
| --- | --- |
| Android | 手机身份密钥、配对设备、各设备同步进度、项目与会话状态。任务输出和审批正文首版只在授权连接期间保留于内存 |
| 阿里云 Relay | 接入与路由元数据、设备在线状态、短时配对路由。按已认证的接入方限制路由，转发内层 TLS 字节流 |
| Windows Agent | 项目授权、手机授权、工具凭据、任务和审批状态、日志与审计。每次操作以本机状态判定是否允许 |
| Windows 托盘与设置 | 通过受权限控制的本机 IPC 查询服务和编辑配置。Agent 根据 Windows 调用者身份决定能否修改本机授权 |

公网外层为可信域名的 WSS。手机和目标 Agent 在每个独立的逻辑通道中完成内层 TLS 1.3 认证和加密。首个原型使用每个目标设备一个独立通道，验证双机时序、关闭和重连。配对后的业务连接须验证双方已登记的身份。外层接入凭据只提供 Relay 路由权限。

## 配对和撤销

1. 电脑本地发起配对，显示短时一次性二维码。二维码包含 Relay 地址、设备 ID、配对标识和主机公钥指纹。配对入口仅开放本次配对所需的操作。
2. APK 用二维码中的公钥指纹验证目标 Agent，通过加密通道提交手机公钥。电脑显示待配对手机和双方可比对的确认信息，用户在 Windows 本地确认后才登记手机身份。成功或到期时使配对标识失效。
3. 后续连接使用持久密钥证明身份。手机私钥保存在 Keystore，电脑端私钥由操作系统凭据保护。普通断网和重启沿用既有配对。
4. Windows 本地撤销手机后，Agent 立即关闭该身份的连接，拒绝后续请求，并同步清理 Relay 路由授权。Agent 的拒绝先于 Relay 同步生效。

## 消息、权限与恢复

内层应用协议使用 UTF-8 JSON。原型验证使用有长度上限的逐行 JSON。消息携带 `version` 和 `type`。请求携带 `requestId`，响应关联原请求，事件携带 Agent 分配的游标。接收端限制消息和缓冲大小，并明确返回不支持的版本。接入身份由握手提供，消息字段不能改变发送方身份。

| 操作 | 所需标识和约束 |
| --- | --- |
| 查询项目与能力 | 已配对手机只能查询该 Agent 当前开放的项目名称、`projectId` 和已验证的适配器能力 |
| 创建或继续会话 | 携带 `projectId`、`adapterId`，继续已有会话时携带 `sessionId`。Agent 验证会话的项目和适配器归属，并从本机授权记录解析工作区 |
| 提交、取消、查询任务 | 提交用 `requestId` 去重，查询和取消使用 `taskId` 并检查项目归属。相同请求 ID 和内容返回原结果，内容不一致时拒绝。取消结果以工具或进程退出状态为准 |
| 处理审批 | 携带 `projectId`、`adapterId`、`sessionId`、`runId`、`approvalId` 和决定。Agent 校验授权、审批有效期和工具允许的决定，一次审批只接受一个结果 |
| 读取日志和同步 | 只返回当前授权项目的数据。每台 Agent 单独管理游标。快照返回同一状态下的游标，客户端随后接收更新。历史事件回放前重新校验项目权限 |

任务提交先持久记录身份、请求和任务状态，再启动工具。断线后 APK 先查原请求结果。若 Agent 重启时无法确认已登记的任务是否启动，保留记录并标为已中断，继续会话由用户显式发起。待审批由 Agent 计时，运行结束或重启后失效。

停用或移除项目时，先提交本机授权变更，阻止后续调度、审批和日志读取，再取消相关远程运行，并使其待审批失效。适配器需能追踪其启动的进程并报告实际取消结果。APK 收到变更、断开授权连接或回到前台重新验证时，清除失效的任务输出与审批正文。连接中断期间的设备和会话摘要标为可能过期。

## 工具执行约束

- 本机授权列表默认为空。手机端的项目操作均以 `projectId` 选项目，工具工作目录由 Agent 按本机记录给出。
- 服务校验目标目录的真实位置，并验证运行期间工具的文件和命令能力受操作系统权限或工具沙箱约束。符号链接、目录联接、会话恢复及子进程都纳入验证。单凭工作目录无法构成权限边界。
- 首版只转发工具明确提供的审批选项，界面默认提供单次批准与拒绝。审批无法完整展示或适配器无法维持项目权限时，相应操作不可用。
- 审计记录发起方、设备、项目、任务、操作及结果。凭据及配对密钥不写日志。公网故障时本机仍可查看运行状态和审计记录。

具体配对封包、TLS 实现、消息上限和超时值在原型中验证后固定到协议版本。实现前先约定跨端错误语义，至少覆盖设备离线、项目未授权、适配器未就绪、审批过期和同步游标失效。
