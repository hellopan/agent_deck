## Windows 端按设计稿重建为三页（提交 ad0d9bb）

用户指出电脑端一直没按 `design/ui-v2.html` 重构，设置页还留着 Codex 路径、配置目录、项目授权清单、任务收件箱等手动配置。

**改动**
- 窗口骨架：44px 顶栏（品牌/主机/短码/AGENT 状态）+ 56px 图标导航 + 34px 状态栏，三页：状态/任务/设置。删除连接、项目、日志三个旧页。
- 状态页：通道卡（已就绪/已停止/未注册，端点、运行时长、三态说明、事件）、本机身份、已配对手机（扫 `pairing/trusted-*.local.json`，读 PEM 证书到期）。
- 任务页：FlowLayoutPanel 队列卡片（自绘 QueueRow）、详情、自绘 `TraceView` 执行轨迹（JSONL 解析 + 按类型着色 + LIVE 跟随），合并旧日志页。
- 设置页：项目白名单只读表格 + 管理入口、常驻与自启状态（读 `HKLM\SYSTEM\CurrentControlSet\Services\AgentDeckLab`）、编辑器检测三行（名称/版本/路径/能力）、任务日志目录（唯一可编辑路径）。
- `agentfind.Tool` 增加 `Version`，`DetectAll` 用 `codex.exe --version` 填充（3s 超时，`hideWindow` 防闪窗）。
- 冒烟脚本改为三页，渲染 `state.png` / `tasks.png` / `settings.png` / `settings-detected.png`，删除 `connection.png`。

**踩过的坑**
- `Panel`/`TableLayoutPanel`/`FlowLayoutPanel` 不支持 `BackColor = Transparent`，自绘控件必须 `SetStyle(SupportsTransparentBackColor)` 后才能用。
- `TableLayoutPanel` 在 `AutoScroll` 容器里把剩余高度给最后一行，队列卡片被拉满 → 改 `FlowLayoutPanel`，宽度用 `ResizeQueueRows()` 同步。
- `RichTextBox` 在 `DrawToBitmap` 下内容为空，且无法按事件着色 → 自绘 `ScrollableControl`。
- 未显示的窗体位于 (-32000,-32000)，冒烟里判断控件是否在窗口内必须沿父链累加 `Left/Top`。
- 桌面宽度预算：900x660 时设置页内容高于视口，靠 `AutoScroll` 滚动，断言按 1120x720 检查。
