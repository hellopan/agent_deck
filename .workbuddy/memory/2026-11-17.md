## 功能补齐（11-17 夜）

- **项目权限**：`projects.Entry.Mode`（`read-only` / `workspace-write`，缺字段按只读），`ResolveMode` 返回目录 + 模式，`codexprobe.Config.Sandbox` 决定会话沙箱，`runWhileAuthorized` 同时比对目录与模式（收窄权限会中断在跑的任务）。队列条目带 `sandbox`，托盘详情显示「只读 / 可写」。
- **撤销配对**：`pair-revoke` 删 `trusted-<device>-<指纹>.local.json`；Agent 每条隧道握手都重读信任目录，所以下次轮询即失效，无需重启。托盘每行「撤销」走二次确认。
- **服务自启**：`service-install` / `service-uninstall`（`x/sys/windows/svc/mgr`，自动启动、先停后删）。托盘走 `runas` 提权，状态问 SCM（`ServiceControl.Query`，P/Invoke OpenSCManager/QueryServiceStatus）；服务装上后托盘不再起自己的 Agent，避免同设备两条连接。
- 修了两个让服务「装上却连不上」的坑：`service` 模式没有 `-pairing-dir`（任何手机都过不了授权），设备 ID 只认 `a`/`b`（真实 32 位十六进制被拒）。
- **未验收**：服务需要已注册的机器才能装（托盘按钮在未注册时禁用），「重启停在登录界面仍能上线」必须实机做过才算完。

## 界面细节经验

- `FlowLayoutPanel` 不拉伸子控件，且**隐藏页**里的控件可能拿到最终宽度却不触发 `SizeChanged`——要同时挂 `Layout` 事件并在赋值前比对宽度，否则右侧按钮会永远挤在内容后面。
- `DeckTheme.Chip` 现在带 3px `Region` 圆角；`Round()` 依赖 `SizeChanged`，AutoSize 标签加进父容器后会被重新计算，够用。
- `DataGridViewComboBoxDisplayStyle.Nothing` 的单元格看起来就是纯文本，必须在提示语里写明「点『权限』列可改」，否则没人知道能点。
