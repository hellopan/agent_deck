## 换 Relay 证书后 PC 自动改钉（`e34cbac`）

- `enroll -replace`：地址或证书钉扎不一致时改钉，**保留设备 ID 与路由令牌**，只重写 `agent.local.json`。
  保留 ID 是关键：服务命令行与手机设备列表都写着它，换 ID 就得重装服务、重配每台手机。
- 写入必须用新的 `replaceFile`（staging + `Root.Rename`）。`publishSubmission` 用 `Root.Link`，**故意不覆盖** —— 这正是 `relay-init` 报 `file exists` 的同一个机制，别拿它改写已有配置。
- 电脑端：`pinned` / `belongs to another Relay` 两个错误走确认弹窗，确认后改钉；`pairing\` 先改名留底，**改钉失败再原样放回**。停止 Agent 放在改钉成功之后，失败时用户手上那个还在跑。
- 开机自启服务启动时读一次配置，改钉后仍用旧证书 —— 只能重启电脑生效，界面记一条而不是装作没事。
- 实测（本机真 relay）：同端口重签 → 不带 `-replace` 报 pinned、带了成功且 ID 不变；换端口 → 报 belongs to another Relay、带了成功且 `relayUrl` 被改写。配置里的证书指纹与 `relay-init` 输出逐字一致。

## 深色主题（tokens §10 + 附录 A + `design/v3-d-compare.png`）

- 用户提供一份 Codex 主题 JSON（surface #0d1117 / ink #e6edf3 / accent #1f6feb / contrast 60 / opaqueWindows true / diffAdded #3fb950 / diffRemoved #f85149 / skill #ad7bf9 / ui Inter）。
- **采纳**：三层 surface 结构（重取值 `bg #141618` / `card #1b1e21` / `bg-alt #101214`）、opaqueWindows 不透明、contrast 用思路不用数值、语义色白名单极短、`#3fb950` 作深色 ok。
- **拒绝**：`accent #1f6feb`（蓝色撞「行动色禁蓝」）、`ink #e6edf3`（偏蓝，改 `#e4e7ea`）、`skill #ad7bf9`（第四个语义色会毁掉颜色=状态）、`fonts.ui Inter`（Win 小字号 Segoe UI 更稳）、codeThemeId（轨迹不做语法高亮）。
- **关键判断：主按钮深色下必须反相**。浅色是近黑底白字，深色改近白底深字（`#e6e9ec` / `#141618`）。规则「对比度最高=主行动」不变，方向翻转；否则按钮消失在底色里。手机发送键同理。
- 深色状态色只提亮不改色相：ok 140°、warn 38°、danger 2°；`link` 仍与 `warn` 同值（深色 `#d9a23c`）。
- 手机深色比 PC 暖 2 个点，但小到不指认不出——低明度会放大色相偏差，暖调明显就显脏。
- 切换跟随系统、无手动开关；深色下唯一保持浅底的是二维码（要能扫）。
- `bg-sunken` 改名 `bg-alt`：浅色比 bg 亮、深色比 bg 暗，它是「不同层」不是「下沉」。
- 用户明确：**不做高对比度模式、不做方角、手机不适配横屏**，已写进 tokens §11「明确不做」。

## 两份样稿支持深色（v3-windows / v3-phone）

- 做法：先把**全部硬编码颜色抽成 CSS 变量**（PC 稿 86 处、手机稿 40 余处），再加 `:root.dark{}` 覆盖块；两稿右上角各加一个评审用切换按钮，`?theme=dark|light` 可强制，不带参数跟随系统并写 `localStorage['ad-theme']`。
- 新增 token：`--act/--on-act`（主行动反相）、`--bg-alt`（浅色提亮/深色压暗）、`--item-active`、`--ev-line`、`--code-bg`、`--pv-bg`、`--tabbar`、`--indicator`、`--qr-fg`、`--on-red`。
- **三个实现陷阱**（写代码时会再遇到，已写进 tokens §10.4）：
  1. 主行动色必须是独立 token；样稿里所有 `color:#fff` 深色下要吃 `on-act`，否则发送键变「近白圆+白箭头」消失。
  2. 内嵌代码块深色下要**更暗**（`#101210`）而非更亮，按「都往上提亮」的惯性做会浮起来。
  3. 时间线竖线不能和卡片框线共用 `line`（深色下不可见，需 `#443e36`）；数字角标深色下是红底深字，`#f85149` 上白字只有 3:1。
- 浅色侧回归验证通过（PC 首页、手机任务页与改版前一致）。
- 产出：`design/v3-wd-{host,projects,perm,logs,settings}.png`、`design/v3-pd-{tasks,approvals,approval-detail,trace,devices,device-detail}.png`。
